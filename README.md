
# AWS Cloud Portfolio – Salim Khan

A professional and responsive DevOps portfolio website built using HTML5 and CSS3.

## Project Overview

This project demonstrates practical knowledge of cloud object storage, static website hosting, CDN configuration and HTTPS using AWS services.

## Run Locally

Clone the repository:

```bash
git clone https://github.com/Salim-0018/aws-cloud-portfolio.git
cd aws-cloud-portfolio
```

Start local server:

```bash
python3 -m http.server 8000
```

Open:

http://localhost:8000

## AWS Deployment

The planned deployment architecture:

1. Create an AWS S3 bucket.
2. Upload website files.
3. Configure CloudFront Origin Access Control.
4. Connect S3 bucket with CloudFront.
5. Configure HTTPS.
6. Test the deployed website.
